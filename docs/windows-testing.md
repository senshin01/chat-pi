# Windows 実機での確認

クラウドの Linux 環境では物理 Windows オーディオ出力は検証できません。
以下は実機で行う受け入れ確認です。自動テストの成功と実機の成功は区別してください。

## 基本再生

1. ZIP をすべて展開し、`ChatPi.exe` を起動。設定を開き、WASAPI 排他と再生デバイスを選択。
2. Windows のサウンド設定のデバイスの詳細で「アプリケーションによりこのデバイスを排他的に制御できるようにする」を許可。
3. ステレオ WAV 44.1 kHz / 16 bit を開く。自動再生、左右の音、タイトル、経過時間、出力レートを確認。
4. WAV 48 / 96 kHz、24 bit、モノラル、float32、MP3 をそれぞれ開く。
   対応するレートでは音源と出力の表示が一致し、モノラルでは左右同じ音が鳴ることを確認。
5. 一時停止、再開、停止、シーク、再生終了後の再開を確認。停止・終了後に他のアプリが同じデバイスを使えることを確認。
6. ジャケット付き MP3、タグなし WAV、日本語・空白のあるパス、壊れたファイルを試す。
   壊れた画像はプレースホルダーを表示し、再生できない音源はエラー表示することを確認。

## WASAPI の失敗と共有モード

- 別のアプリで同じデバイスを排他使用した状態で再生し、エラー表示することを確認。
- デバイスが対応しない形式を開き、別のレートや共有モードへ黙って切り替えないことを確認。
- 共有モードを明示選択すると再生できること、画面に Windows ミキサー経由と表示することを確認。
- USB デバイスを抜いた場合はエラーになること。再接続後、必要なら設定でデバイスを選び直して再生。

## ASIO

1. メーカーの x64 ASIO ドライバーを導入し、設定で ASIO とドライバー、出力開始チャンネルを選択。
2. バッファサイズはメーカーのコントロールパネルで設定。
3. 44.1 / 48 / 96 kHz の対応レートと 16 / 24 bit の WAV、MP3 を再生。ドライバー側のレートとアプリの表示を確認。
4. 出力チャンネルの選択、左右の音、停止、再生終了、曲切り替え、シークを確認。
5. 未対応レート、存在しないチャンネル、デバイス未接続で、明確なエラーが表示されることを確認。
6. ドライバー設定の変更で reset request が来た場合、エラー表示後にファイルを開き直して再生できることを確認。

ASIO の対応表現は README に記載。未対応の形式を使うドライバーはエラーとなります。
DSP オフでは精度を下げる整数変換を行いません。DSP オンでは機器の有効ビット数へ明示的に量子化します。

## EQ / PCM アップサンプリング

1. 旧版の設定で起動し、EQ / SRC が初回オフであること、MP3 / WAV / FLAC の元レート出力が維持されることを確認。
2. ASIO で44.1 kHzの音源を開き、設定の「音声処理」で2倍を適用。機器側とアプリの出力が88.2 kHzになること。4倍では176.4 kHz。
   48 kHzでは96 / 192 kHzを確認。機器が対応している場合は96 kHz ×4 = 384 kHzも確認。
3. 未対応の倍率では明確なエラーになり、共有モードや別レートへ自動変更しないことを確認。倍率を戻せば再生できること。
4. SRC オフで EQ だけをオンにし、バンドを調整・適用。音色が変わり、機器のレートは元のままであること。フラットに戻す機能も確認。
5. EQ と SRC を同時に使う。複数バンドを上げると表示のプリアンプ減衰が増え、手動で −3 dB加えるとさらに3 dB下がること。
6. 同じ倍率の DSP 再生中に EQ / プリアンプを変更して適用。ドライバーを開き直さず反映し、大きなクリック音が出ないこと。設定画面の保存／適用／キャンセルも確認。
7. 自動対策をオフにして強い増幅を設定した場合、ピーク超過が表示されること。手動プリアンプを下げ、超過が増えなくなること。
8. 一時停止中に倍率を変更して保存。一時停止と位置を維持し、再生すると新しい倍率で出力すること。
9. EQ / SRC 使用中のシーク、末尾への移動、リピート、別の音源レートへの切り替えで、古い音声が混ざらず最後まで再生できること。
10. アプリを終了して別の曲で起動し、EQ のオン／オフと全バンド、倍率、プリアンプ、先読み設定が保存されていること。
11. 先読み40 msから始め、通常のPC操作と長時間再生でバッファ不足回数・音切れを確認。発生する場合は先読み／ドライバーバッファを増やす。
12. WASAPI 排他でも同じ EQ / SRC の確認を行う。共有モードは Windows の追加変換があることを踏まえて確認する。

### SRC オフへの復帰と ASIO の無音切り分け

1. 同じ FLAC で EQ オフ、SRC 2倍／4倍で再生 → SRC オフを保存 → 終了 → 再起動して再生。音とネイティブレートの両方を確認。
2. 同一アプリ内で2倍／4倍からオフに戻した場合も確認。44.1 / 48 / 96 kHz、16 / 24 bit FLAC、WAV / MP3 でも試す。
3. EQ と SRC が両方オフなら、保存された手動プリアンプと自動対策の状態に関係なく、適用プリアンプが0 dBであること。
4. 無音の場合は `%LOCALAPPDATA%\ChatPi\audio.log` の該当起動分を保存。`requested` と `actualRate`、`output`、`callbacks`、`bytes`、`nonzeroBuffers`、`underruns` を確認する。
   `nonzeroBuffers > 0` はアプリから ASIO の出力メモリーへ非ゼロ音声を渡したことだけを示す。ドライバーや DAC での再生は別途確認する。
5. レート不一致や初期化中の音声形式変更は無音で続行せず、エラー表示すること。同じレートの再生・リピートでは追加の開き直しを行わないこと。

## ダブルクリック・設定保存

1. 設定で既定アプリ候補に登録し、Windows の既定アプリ画面で使いたい拡張子を Chat Pi に設定。以前の版で登録済みの場合も再登録し、追加形式が候補に入ることを確認。
2. Explorer で音楽ファイルをダブルクリックし、1 ウィンドウで自動再生することを確認。
3. 別の音楽ファイルをダブルクリックし、既存ウィンドウで再生が切り替わることを確認。
4. アプリを終了して再起動し、出力モード・デバイス・バッファ・ASIO 開始チャンネルが保存されていることを確認。
5. 設定の登録解除を実行し、別の既定アプリを Windows で選べることを確認。

## リピート・テーマ

1. 短い MP3 / WAV を再生し、矢印のリピートボタンをオンにする。曲の自然終了時に同じ曲が先頭から再生されること、レートが変わらないことを確認。
2. 再生中にリピートをオフにし、曲末で停止することを確認。オンでも停止ボタンを押すと停止することを確認。
3. リピートオンでアプリを終了し、再起動後もボタンがオンであることを確認。
4. 設定でライト／ダークを選び、保存。背景、文字、ボタン、設定画面の選択欄が切り替わり、再生位置と音声出力が維持されることを確認。
5. 一時停止中にもテーマを切り替え、一時停止が維持されることを確認。キャンセルではテーマが変わらないこと、再起動後に保存したテーマが復元されることを確認。

## シークバー

1. MP3 / WAV を再生し、ノブを前後にドラッグ。ドラッグ中に時刻表示が選択位置に対応し、ノブが現在の再生位置へ戻らないことを確認。
2. ノブを離すと選択した位置から音が再生され、その位置から進行表示が続くことを確認。バーの途中をクリックしてもその位置へ移動することを確認。
3. 一時停止中に移動し、一時停止が維持されることを確認。再生ボタンで選択した位置から再開することを確認。
4. バーにキーボードフォーカスを置き、矢印、Home / End、PageUp / PageDown を操作。キーを離すと選択位置が反映されることを確認。
5. ドラッグしたままバーの外でマウスを離しても選択位置が反映されること、操作後に進行表示が更新され続けることを確認。
6. WASAPI / ASIO のどちらも、シーク前にバッファに残った音が混ざらず、元のレートを維持して再開することを確認。

## 追加形式

1. FLAC / ALAC の 44.1 kHz / 16 bit、96 kHz / 24 bit を WASAPI 排他と ASIO で再生し、機器側のレートとアプリの表示が一致することを確認。
2. AAC（M4A と ADTS AAC）、AIFF、Ogg Vorbis、WMA を開く。ファイル選択、ドラッグ＆ドロップ、ダブルクリックのすべてで再生できることを確認。
3. 各形式で、一時停止中・再生中のシーク、末尾付近への移動、先頭への移動、リピートを試す。Ogg は数分の曲でも後半へのシークを確認。
4. FLAC / ALAC / Ogg のタグ、ジャケット付きファイルの表示、日本語・空白を含むファイルパスを確認。
5. DSF / DFF、DRM 付きファイル、壊れたファイルはエラーになり、別の正常なファイルを開くと再生できることを確認。

Windows CI は自作の実ファイルでデコードとシーク、FLAC / ALAC の 24 bit サンプル精度、リピートを検証します。物理デバイスの出力は上記の実機確認が必要です。

この初期版は未署名です。コード署名とインストーラーは今後の配布段階で追加する項目です。

## 形式別ファイルアイコン

1. 最新版 ZIP をすべて展開し、`Assets/FileIcons` に ICO ファイルがあることを確認。
2. 設定の「登録して Windows の設定を開く」を押し、各拡張子に Chat Pi を選択。旧版で設定済みの場合も選び直す。
3. 同名の MP3 / WAV / FLAC / M4A / AAC / AIFF / Ogg / WMA をエクスプローラーで表示し、それぞれの形式名がアイコンに表示されることを確認。
4. 「詳細」表示の小さいアイコン、大きいアイコン、高 DPI 設定で確認。必要ならエクスプローラーを更新する。
5. `.aif` は AIFF、`.oga` は OGG、AAC / ALAC を格納した `.m4a` はいずれも M4A と表示され、ダブルクリックで再生することを確認。
6. 別フォルダーへ移して再登録し、アイコンとダブルクリック起動を確認。登録解除後も、他の再生アプリの候補が維持されることを確認。
